使用说明

这是什么

ESP-WebSDR 是一个纯浏览器端的频谱查看器。它通过 WebSerial 直接读串口，把 ESP32 芯片内部那条未公开的原始 I/Q 采样通道变成一台低成本的 2.4 GHz 软件无线电接收机；不经过任何服务器，数据不离开本机。

三步上手

  1. 把开发板用 USB 接到电脑（优先使用板上的原生 USB 口，而不是 CH340/CP2102 那种串口桥）。
  2. 打开「刷写固件…」，选择与芯片匹配的固件并写入。刷好后拔下设备等 5 秒再插回。
  3. 回到本页点右上角「连接 ESP-SDR」，然后设置中心频率，频谱与瀑布图就会开始刷新。

参数怎么选

只看 2.4 GHz 有没有信号、想快速摸清环境：用「片上频谱」，80 MS/s 覆盖整段 ISM，配合 1024 或 2048 频点。

想看清某个窄带信号、或需要原始 I/Q 自己做处理：用「I/Q 流」，降低采样率（例如 20 MS/s）能让每帧更长、更连续。

信号弱：先确认增益（硬件 AGC 或手动调高），再考虑缩小模拟带宽压低底噪，最后才用迹线平均。

重要限制

  • 数据是间断的：串口带宽远小于射频采样率，除个别芯片的连续模式外，两次采集之间会丢信号，因此不适合解调连续数据。
  • 频段有限：只有 2.4 GHz 附近（ESP32-C5 额外支持 5 GHz），收不到 433 MHz、HF 或卫星信号。
  • 增益与功率未标定：dBFS 数值是相对值，不能当作绝对功率计量。
  • 仅接收：项目不提供发射实现。接收本身一般无需许可，但发射或干扰在多数地区违法。
  • 需要桌面浏览器：WebSerial 只在 Chrome、Edge、Firefox 桌面版可用，并且必须通过 HTTPS 或 localhost 打开。

常见问题

连接失败或一直显示「未连接」？
确认没有别的程序占用串口（串口监视器、esptool、其他 SDR 软件）；确认已刷入 ESP-SDR 固件；插拔一次让板子复位；必要时按住 BOOT 再插入以进入下载模式重新刷写。
出现 CRC 错误或采样丢失？
页面会自动提示。降低采样率、减小 FFT 频点数、换用原生 USB 口、或按提示切换到 1 MBaud 串口速率通常都能改善。
频谱只有一条中间尖峰、看不到信号？
那是零中频的直流泄漏，正常现象。点击频谱或瀑布图可以把关注频率移开 0 Hz，也可以在「零中频处理」里选择填充 DC 频点。
支持哪些芯片？
ESP32、ESP32-S2、ESP32-S3、ESP32-C2/C3/C5/C6/C61、ESP32-H2、ESP32-S31 均可刷入 ESP-SDR；具体可用采样率、带宽与片上频谱能力由固件协商决定。
中间出现一块 20 MHz 宽的平坦台地？
那不是信号，是接收通道的模拟滤波器通带。当「模拟带宽」比「采样率 / 名义跨度」窄时，两侧会被接收机自己削掉，只剩中间这一条。判据：改中心频率它跟着走、改模拟带宽它的边缘跟着动，就是滤波器；勾选「全开」即可看到整个跨度。
怎么看信号占的是哪个 WiFi 信道？
打开「显示 2.4G WiFi 信道」，频谱上会按 20 MHz 画出信道 1–14 并标号，1/6/11 高亮（唯一互不重叠的组合）。信号压在哪条色带里就是哪个信道；鼠标悬停与「中心」读数也会直接报出信道号。

接收机

频率、增益与带宽决定「怎么收」。先设中心频率，其余保持默认即可。

本振频率。ESP32-S3 可尝试 2.2–2.7 GHz，但可靠工作的范围是 2.4 GHz ISM 频段。也可以直接单击频谱或瀑布图调谐。

零中频接收机在 0 Hz 处有一条直流 / 本振泄漏尖峰。「填充 DC 频点」把它抹平，「偏移本振」把关注频率挪开 0 Hz。

硬件 AGC 由芯片自动调节；需要固定条件对比时用手动档。增益档是芯片增益表索引，不是 dB。

接收通道的模拟滤波器带宽。越窄底噪越低，但会削掉信号边缘。它比「采样率 / 名义跨度」窄的时候，频谱两侧是被接收机自己削掉的，中间那块平坦台地只是滤波器通带、不是信号。

一屏能看到的频谱宽度。采样率越高，覆盖越宽、单次采集越短，串口压力也越大。80 MS/s 可覆盖整个 2.4 GHz ISM 频段。

捕获模式

由 ESP32 自己算好 FFT 再回传：数据量小、刷新快；部分芯片还能连续采集射频。

片上频谱由 https://www.z2labs.io

把原始 I/Q 采样传到电脑做 FFT：频点数可调、实现透明，但受串口带宽限制，采样是间断的。

频点数越大，频率分辨率越高（RBW 越细），但每帧需要更多采样，刷新率下降。2048 是通用折中。

8+8 位传输更快，适合高采样率；10+10 位量化噪声更低，弱信号更清楚。

显示

底噪决定瀑布图颜色从哪里开始，动态范围决定颜色覆盖多少 dB。开启「自动缩放」会按当前噪声自动调整。

对相邻帧做指数平均，噪声更稳、弱信号更明显，但会掩盖快速变化。

逐频点保留历史最大值，用来发现间歇性突发（如蓝牙广播）。

在频谱上标出 2.4 GHz WiFi 的 1–14 信道（每个约 20 MHz 宽）。1、6、11 三个互不重叠，图中高亮，最值得关注；信号落在哪条色带里，就说明它占着哪个信道。鼠标停在频谱上还会直接报出信道号。

在频谱上标出 2402.5–2472.5 MHz 这一段——DJI 无人机图传与遥控常用的 2.4 GHz 频段范围。该区间被淡紫色覆盖、两侧画实线边界，区间名标在频谱上方。用来快速判断图传信号有没有落进这个范围；纯显示层，不影响采样与 FFT。

瀑布图把频谱随时间的变化叠成一张图，适合找间歇性信号（蓝牙广播、跳频、无人机图传）。它每帧都要逐像素重画，是本页最费 CPU 的一块：只关心实时频谱时把它关掉，功率谱会自动占满整块高度，绘制开销也随之省下。关掉期间不积累历史，重新打开从当前时刻继续。选择会被记住；未连接时它总显示，因为那块地方放的是「三步上手」引导。
